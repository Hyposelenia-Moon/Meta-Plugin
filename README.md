# Meta-Plugin

TRSS-Yunzai v3 插件：**原神攻略 · 强度榜单 · 练度查询**。
（原数据仓库 `Character-Codex-Data`；2026-10 改造为独立插件，并整体并入 `Mhydps-Plugin` —— 后者已废弃。）

## 依赖

| 依赖 | 必需性 | 用途 |
|---|---|---|
| [miao-plugin](https://github.com/yoimiya-kokomi/miao-plugin) | ✅ 必需 | 图鉴版式 / 字体 / 图标 / 别名 / 面板取数 / 伤害计算引擎（**复用而不复制**它的资产） |
| Atlas-Plugin | 可选 | 图鉴类资源补充；**缺失或异常只降级、不报错** |
| 本地代理 | 可选 | 榜单 / 危战 / 练度联网时需要（国内直连 `www.mhydps.cn` 会在 TLS 握手阶段失败） |

## 安装与更新

1. 把本仓库放进 bot 的 `plugins/Meta-Plugin`（目录名保持 `Meta-Plugin`）。
2. bot 内发 `#更新Meta`（= `#更新Meta-Plugin`）。
   ⚠ 部署副本里一旦有本地改动，普通 `#更新` 会被 git 拒绝 —— 此时用 `#强制更新Meta`
   （注意它会 `git reset --hard`，会丢弃该目录里的本地改动，先备份）。

## 命令

帮助入口：`#meta`（总）/ `#攻略帮助`（攻略 + 练度）/ `#DPS帮助`（伤害 + 榜单）。

| 命令 | 说明 |
|---|---|
| `#胡桃攻略` / `#胡桃攻略2` / `#胡桃指南` | 角色攻略（唯一攻略入口，后缀式） |
| `#胡桃dps [金数]` | 该角色各金档能打到的最高伤害队伍（含视频） |
| `#危战 [版本/首领/角色]` | 幽境危战 n6 / n7 两档谁最快 |
| `#练度查询 胡桃` | 我的配装 vs 攻略目标 → 总体练度 + 面板档 + 提升建议（**不带 UID**，账号走 miao 的米游社绑定） |
| `#队伍伤害 胡桃 行秋 夜兰 钟离` | 整队关键伤害；可加 `轴:重击×8@21s`、`词条:暴击率+20` |
| `#配装 胡桃 [名次]` | 阿卡莎角色榜上榜者配装（需联网与代理） |
| `#DPS榜 胡桃 金≤12` | DPS 榜（兼容别名） |
| `#DPS危战榜 7.1` | 危战榜（兼容别名） |
| `#DPS练度查询 胡桃` | 阿卡莎名次面板（兼容别名） |
| `#DPS视频 3` / `#DPS危战视频 3` | 榜单 / 危战视频 |
| `#DPS状态` | 数据与资源状态（含 miao / Atlas 是否就位） |
| `#DPS更新`（仅主人） | 拉取榜单数据 |

命令与触发词的完整口径（含路由优先级与负向断言）见 [docs/功能与命令.md](./docs/功能与命令.md)。

## 配置

- 首次启动自动从 `config/config.yaml.example` 生成 `config/config.yaml`（**不入库**）。
- `networkEnabled` **默认关**：需要榜单 / 危战 / 练度联网时手动开启；`proxy` 供 `mhydps.cn` 使用；
  `akashaEnabled` + `akashaProxy` 供练度侧（浏览器会话）使用。
- 米游社 ck 由 **miao** 保存，本插件不保存任何凭据；状态页只回显"是否配置代理"。

## 数据与许可

- 攻略数据由本仓库维护产出（`data/gi/*.json`），流水线见 [docs/](./docs/) 下的数据册；运行时**只写** `out/` 与 `config/`。

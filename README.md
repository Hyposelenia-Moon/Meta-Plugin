# Meta-Plugin

TRSS-Yunzai v3 插件：**原神攻略 · 强度榜单 · 练度查询**。
（原数据仓库 `Character-Codex-Data`；2026-10 改造为独立插件，并整体并入 `Mhydps-Plugin` —— 后者已废弃。）

## 依赖

| 依赖 | 必需性 | 用途 |
|---|---|---|
| [miao-plugin](https://github.com/yoimiya-kokomi/miao-plugin) | ✅ 必需 | 图鉴版式 / 字体 / 图标 / 别名 / 面板取数 / 伤害计算引擎（复用其版式/字体/图标/别名与面板取数；元素底为其派生件，见「资源来源与许可」） |
| Atlas-Plugin | 可选 | 图鉴类资源补充；**缺失或异常只降级、不报错** |
| 本地代理 | 可选 | 榜单 / 危战 / 练度联网时需要（国内直连 `www.mhydps.cn` 会在 TLS 握手阶段失败） |

## 安装与更新

1. 把本仓库放进 bot 的 `plugins/Meta-Plugin`（目录名保持 `Meta-Plugin`）。
2. bot 内发 `#更新Meta`（= `#更新Meta-Plugin`）。
   ⚠ 部署副本里一旦有本地改动，普通 `#更新` 会被 git 拒绝 —— 此时用 `#强制更新Meta`
   （注意它会 `git reset --hard`，会丢弃该目录里的本地改动，先备份）。

## 命令

帮助入口：`#meta`（总）/ `#攻略帮助`（攻略 + 练度）/ `#DPS帮助`（伤害 + 榜单）。

| 命令 | 说明 |
|---|---|
| `#胡桃攻略` / `#胡桃攻略2` / `#胡桃指南` | 角色攻略（唯一攻略入口，后缀式） |
| `#DPS榜 [角色] [金数] …`（`榜` 可省 = `#DPS`） | 配队总榜；**带角色名 = 该角色各金档能打到的最高伤害队伍** |
| `#危战 矮灵 n7` | 幽境危战分档成绩：**须指定档位** —— n7 = 速通档（≤70s）、n6 = 险胜档（>70s）；两档都按耗时**降序**；不写档位会提示选档 |
| `#练度查询 胡桃` | 我的配装 vs 攻略目标 → 综合档 + 当前配装明细 + 提升建议 + 参考 DPS + 角色立绘（**只写角色名**，账号走 miao 的米游社绑定） |
| `#练度榜 胡桃 [名次]` | 阿卡莎角色榜（**榜单数据，与自己的账号无关**）：省略名次 = 前 20 名；写名次 = 该名次配装详情（需联网与代理） |
| `#队伍伤害2 胡桃 行秋 夜兰 钟离 +30暴击` | 整队关键伤害；`2` = 配置 `teamDamageAxes` 里的**内置序号轴**（省略 = 1），词条**直接写**、不用加前缀 |
| `#DPS榜 刻晴 48金视频1` / `#危战 矮灵 n7 视频3` | 取该名次的 B 站视频（后缀式；名次 = 当前筛选内按榜单排序的第 N 名） |
| `#meta状态` | 数据与资源状态（含联网开关、已关闭模块、miao / Atlas 是否就位） |
| `#榜单刷新`（仅主人） | 立即重新抓取榜单缓存 |

命令与触发词的完整口径（含路由优先级与负向断言）见 [docs/功能与命令.md](./docs/功能与命令.md)。

## 配置

- 首次启动自动从 `config/config.yaml.example` 生成 `config/config.yaml`（**不入库**）；大部分项可在**锅巴面板**里改。
- **模块开关** `modules.*`（10 个模块，默认全开；**队伍伤害默认关闭**）：关闭的模块命令不响应 ——
  非接管类回一条提示，`#胡桃攻略` / 帮助页这类抢占入口则**不认领**、放行给其他插件。
- `networkEnabled` **默认关**：它**只管辖查询类远程访问与刷新**（DPS 榜 / 危战 / 练度 / 榜单头像下载），
  **不是整个插件的全局联网禁令** —— 别名服务、可选插件探测、依赖安装等不受它影响。
- `proxy` 供 `mhydps.cn` 使用；`akashaEnabled`（阿卡莎**数据通道**开关，与模块开关正交）+ `akashaProxy` 供练度侧使用。
- 米游社 ck 由 **miao** 保存，本插件不保存任何凭据；状态页只回显"是否配置代理"与"已关闭的模块"。

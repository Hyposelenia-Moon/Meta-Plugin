## 2. 精通曲线

普通剧变用 `16×EM/(EM+2000)`；**月反应与星烁用 `6×EM/(EM+2000)`**（`DmgMastery.js` 的 `type === 'lunar' || 'stellar'` 分支）。

## 3. 结算公式（`DmgCalc.js` 的 lunar/stellar 分支）

```text
基础 = eleBaseDmg[level]            // 与剧变同源的等级系数表
伤害 = (基础 × (1 + fypct) × eleBase × num + fyplus)
       × (1 + elevatedNum)          // 「提升乘区」
       × kNum                        // 反应系数乘区
       × (1 + cpct × cdmg)           // 暴击按期望值乘在整段上
```

与普通剧变的三点差异：

1. 精通系数是 6 而不是 16；
2. 多出 `fypct`（专用反应加成）与 `elevatedNum`（提升乘区），不能并进 `damageBonus`；
3. 暴击是显式乘区（`1 + cpct×cdmg`），不是「特殊角色才有的例外」——这也是方案第 478 行说的「反应暴击必须显式规则」。

## 4. 契约字段（已落地）

- `TimelineHit.reaction`（`ReactionDeclaration`）已带 `talent`、`count`、`fypct`、`fyplus`、`elevated`、`kNum`，缺省值与 miao 一致。

- `REACTION_COEFFICIENT` 与 `eleBaseDmg` 同源，可以直接复用现有 92 条表。

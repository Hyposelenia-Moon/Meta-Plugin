# 功能与命令

> 本册是**命令全集与触发口径**的唯一维护处。命令文案、正则、优先级的**代码来源**是
> `src/components/constants.ts`（改命令必须同批改本册）与各 `src/apps/*.ts`。

## 帮助入口（两小一大）

| 入口 | 页面内容 | 规则 |
|---|---|---|
| `#meta` / `#Meta帮助` | 总帮助 | `META_HELP_RULE` `/^#(?:meta\|Meta\|META)(?:帮助\|说明)?$/` |
| `#攻略帮助`（= `#攻略` / `#攻略说明`） | 攻略 + 练度 | `HELP_RULE` `/^#攻略(?:说明\|帮助)?$/` |
| `#DPS帮助` | 配队排行 + 危战 + 队伍伤害 | `RULES.help` |

三者由同一个 handler（`src/apps/help.ts` 的 `MetaHelp.handleHelp`）出图，**渲染失败回落同源文本**。

## 攻略入口（后缀式）

| 命令 | 规则 |
|---|---|
| `#胡桃攻略` / `#胡桃攻略2` / `#胡桃指南` | `CODEX_SUFFIX_RULE` `/^#(更新)?(?!.*设置默认攻略)([^#\s]\S*?)攻略([1-7])?(?:\s*面板图([1-9]\d*))?$/` |
| `#胡桃攻略 面板图3` | 同上（`面板图N` 指定图库里的第 N 张立绘；带不带空格都认） |
| `#攻略列表` / `#攻略状态` | `CODEX_META_RULE` `/^#攻略(列表\|状态)$/` |

- 三个全局词 `#攻略` / `#攻略帮助` / `#攻略说明` 由帮助 app 认领（`accept()` 只认领它们与 `#meta`）。
- **负向断言 `(?!.*设置默认攻略)` 必须保留**：`#设置默认攻略3` 也以「攻略3」结尾，否则会被吞掉。
- **`面板图N`（2026-10-17 加）**：`#胡桃攻略 面板图3` 让攻略页立绘改用图库 `{角色}_{序号}_…` 的第 3 张（与 `#练度查询 胡桃 面板图3` 同口径）。点名要哪张就照用，不再卡「不小于默认立绘」；白边仍按离线清单裁剪 + 模糊层铺满。序号在图库里不存在时退回随机取图，原因写在 `pickPagePortrait().note` 里。
- `CODEX_GUIDE_RULE`（`^#(.+)指南$`）与 `CODEX_ARG_RULE`（`^#攻略\s+(.+)$`）**入口已移除**，只留给 `src/modules/branches.ts` 的解析器使用；**不得加回命令入口**。

## 练度评分口径（`#练度查询`，2026-10-15 用户定；2026-10-27 改为「直接用 miao 面板激活的评分规则」）

- **三维加权**（`gradeWeights`，默认 `comprehensive:65,weapon:20,talent:15`）：`综合` / `武器`（是否在推荐档）/ `天赋`（目标等级）。
  综合**内部**的算法由 miao 的评分规则派生，不再是插件自己维护的固定公式。
- **规则来源 = miao 面板当前激活的评分规则（2026-10-27 用户定）**：读 `getArtisMark(true)` 的
  `charWeight`（miao 面板「评分规则：xxx」用的那份属性权重；来源 `character/<角色>/artis_user.js` >
  `artis.js` > `artifact/artis-mark.js` 的 `usefulAttr` 默认表），按**输出向权重占比**自动分档：
  `atk` + `cpct` + `cdmg` + `dmg` + `phy` 占 `(输出向 + 功能向)` 的比例
  → ≥ 0.65 为 `dps`、≥ 0.50 为 `subdps`、其余为 `support`（功能向 = `hp` + `def` + `mastery` + `recharge` + `heal`）。
  用户在 miao 里改某角色的评分规则（`artis_user.js`），本插件的练度口径自动跟着变。
- **绑定优先级（高 → 低）**：配置 `gradeRuleOverrides` 逐角色 → 配置 `gradeRule` 全局强制
  （`dps` / `subdps` / `support`，整站回退用）→ miao 规则自动分档 → 拿不到 miao 规则时按攻略
  `meta.定位` 兜底。**本插件不再维护逐角色规则数据表**（`_grade-rules.json` 已删除）。
- **四个独立分量**：`mark` 圣遗物词条评分（miao `ArtisMark` 档位，detail 里带 miao 的规则标题）/ `set` 套装（4 件套 / 2+2 / 效果型）/
  `main` 主词条（命中部位比例）/ `panel` 面板目标（达成度平均；多方向取达成度最高的方向）。
  词条与套装**互不派生**，各自一条证据行。
- **内置预设**：

  | 预设 | 权重 | 达标下限 | 缺 miao 评分 | 面板行 |
  |---|---|---|---|---|
  | `dps`（主C） | mark 80 / set 20 | mark ≥ 0.95、set ≥ 0.8 | 判「待评」 | 参考（info） |
  | `subdps`（副C） | mark 45 / set 25 / panel 30 | mark ≥ 0.8、set ≥ 0.8、panel ≥ 0.9 | 判「待评」 | 计分 |
  | `support`（辅助/奶/盾/专辅） | set 40 / main 30 / panel 30 | set ≥ 0.8、main = 1、panel ≥ 0.9 | 不影响 | 计分 |

- **达标判定**：加权分只用于三维条、毕业档与总分；`met` 由预设的各分量下限决定（「综合 96% 但套装不符」会如实判未达标）。
  可用分量少于 `minParts`（默认 2）→ 综合判「待评」，不虚抬。
- **毕业档**（大毕业 / 毕业 / 小毕业）按**综合分**判定；等级不足时最高「小毕业」。
- **圣遗物评分走 miao 的评分规则**（`ArtisMark.getMarkDetail()`：有效词条加权分 + `MAX…D` 档位），页面脚注口径行写明。

- **「最后更新时间」口径（2026-10-17 修正）**：取**攻略数据文件在 git 里的最后提交日期**（`model/guideDate.guideUpdatedDate()` → `git log -1 --date=format:%Y.%m.%d -- data/gi/<角色>.json`，结果按 `文件:mtime:size` 缓存）。**不用 mtime**：`git pull` / 重新克隆 / 编辑器整目录重写都会把 mtime 刷成检出日（实测本机所有 `data/gi/*.json` 的 mtime 都是 2026-10-04，而数据真实提交日是 2026-09-30），改模板/图片/样式更不能影响它。不在 git 仓库里（或没装 git / 超时）→ 返回空串，页面写「未提供」，不猜日期。
- **缓存键含 HEAD（2026-10-17 复审修复）**：只按 `文件:mtime:size` 缓存不够 —— `git commit` 不改这两项，于是「存草稿 → 预览 → 提交 → 再预览」会一直返回提交前的日期。现在缓存键追加仓库 HEAD（`git rev-parse --short HEAD`，2 秒 TTL），一提交即失效重算；未提交的改动仍显示上次提交日期。
- **配队头像间距**：+ 用**显式固定值**（.codex-team .codex-sep { margin: 0 10px; font-size: 24px }）；正文行的紧凑规则收窄为 .codex-row .codex-sep { margin: 0 1px }，两条互不影响（2026-10-17 用户反馈头像间距曾被行内规则带跑）。
- **配队多选槽（2026-10-18 核对修复 #9）**：攻略里的候选写法是 莫娜 / 沃雅妮莎（一个槽位多个候选）。presentation 把名字拆成 lts（原始 
ame 整串保留给文本回退），subViews.withIcons 为每个候选按 character:<名字> 解析图标，模板逐候选渲染：有图标画头像（候选头像 44px）、没图标画名字，候选之间用 .codex-team-altsep（/）分隔；缺头像的成员不再整条消失。
- **比例不卡**：1920×1080 这类大图照样用 —— 主体层按「裁留白后的整块 **cover 放大到铺满**」摆进取景窗（最长边先满、溢出的部分裁掉）并**居中**，所以卡片永远没有空缺，**版面高度始终等于默认立绘的比例**。
- **多张合格 → 随机取一张**（与 miao `lodash.sample` 同口径），同一角色不会每次都是同一张。
- **降级**：池里全是小图 / 读不出默认立绘尺寸 → 用 miao 默认立绘，并把原因写进 `note`（不抛错、不影响出图）。
- **四角圆角 20px**（2026-10-17 用户定，比页面卡片的 10px 大一号、更明显）：只设在 `.codex-portrait` 上，靠 `overflow: hidden` 裁圆。
- **占位值整行不显示**：`meta` 里像 `建议等级: ___级`、`100级提升: ___%` 这种**一个数字都没有、又含 `_` / `—`** 的值，按占位处理（`presentation.isPlaceholderValue`）→ 该行不进 `metaRows`、页面不画；图片与文本回退同源。
- 代码入口：`src/model/ProfileImgRes.ts` —— `pickPagePortrait()` 返回 `{ src, source, note, size, std, ratio, crop, box }`；`planPortraitBox()` 算主体层的宽高与左上角（百分比）；`portraitCropOf()` 读清单里的四边比例；`imageSizeOf()` 读 PNG/JPEG/WebP 头部（零依赖）。

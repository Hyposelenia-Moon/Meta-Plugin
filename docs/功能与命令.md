# 功能与命令

> 本册是**命令全集与触发口径**的唯一维护处。命令文案、正则、优先级的**代码来源**是
> `src/components/constants.ts`（改命令必须同批改本册）与各 `src/apps/*.ts`。

## 帮助入口（两小一大）

| 入口 | 页面内容 | 规则 |
|---|---|---|
| `#meta` / `#Meta帮助` | 总帮助 | `META_HELP_RULE` `/^#?(?:meta\|Meta\|META)(?:帮助\|说明)?$/` |
| `#攻略帮助`（= `#攻略` / `#攻略说明`） | 攻略 + 练度 | `HELP_RULE` `/^#?攻略(?:说明\|帮助)?$/` |
| `#DPS帮助` | 伤害 + 榜单 + 状态 | `DPS_RULES.help` |

三者由同一个 handler（`src/apps/help.ts` 的 `MetaHelp.handleHelp`）出图，**渲染失败回落同源文本**。

## 攻略入口（后缀式）

| 命令 | 规则 |
|---|---|
| `#胡桃攻略` / `#胡桃攻略2` / `#胡桃指南` | `CODEX_SUFFIX_RULE` `/^#?(更新)?(?!.*设置默认攻略)([^#\s]\S*?)攻略([1-7])?$/` |
| `#攻略列表` / `#攻略状态` | `CODEX_META_RULE` `/^#攻略(列表\|状态)$/` |

- 三个全局词 `#攻略` / `#攻略帮助` / `#攻略说明` 由帮助 app 认领（`accept()` 只认领它们与 `#meta`）。
- **负向断言 `(?!.*设置默认攻略)` 必须保留**：`#设置默认攻略3` 也以「攻略3」结尾，否则会被吞掉。
- `CODEX_GUIDE_RULE`（`^#(.+)指南$`）与 `CODEX_ARG_RULE`（`^#攻略\s+(.+)$`）**入口已移除**，只留给 `src/modules/branches.ts` 的解析器使用；**不得加回命令入口**。

## `#DPS…` 命令（合并自 `Mhydps-Plugin`，兼容保留）

| 命令 | 正则 | 权限 | 优先级偏移 |
|---|---|---|---|
| `#DPS榜 [角色] [金数] [标签] [主C] [绿玩] [页N]` | `rank` `/^#?(?:dps\|DPS)榜?(?!视频\|帮助\|状态\|更新\|刷新\|练度\|危战)\s*([\s\S]*)$/` | all | 0 |
| `#DPS危战榜 [版本] [首领] [角色] [金数] [页N]` | `raid` `/^#?(?:dps\|DPS)危战榜?(?!视频)\s*([\s\S]*)$/` | all | -20 |
| `#DPS练度查询 [角色] [UID]` | `build` `/^#?(?:dps\|DPS)练度查询\s*([\s\S]*)$/` | all | -50 |
| `#DPS状态` | `status` `/^#?(?:dps\|DPS)状态$/` | all | -10 |
| `#DPS视频 <名次>` / `#DPS危战视频 <名次>` | `video` / `raidVideo` | all | -100 |
| `#DPS帮助` | `help` | all | -10 |
| `#DPS更新` / `#DPS强制更新` / `#DPS刷新` | `admin` | **master** | -10 |

- **判定顺序**（`matchDpsCommand`）：`video → raidVideo → admin → help → status → build → raid → rank`（视频最优先、榜单兜底），与合并前各 app 的优先级顺序一致。
- 值必须与合并前**逐字一致**（负向断言是路由正确性的关键：`#DPS榜视频` 不能被榜单规则吞掉）。
- 文案已按用户决定修正为 `#DPS视频 <名次>`（原文案 `#DPS榜视频` 与正则不符）。

## v3 新入口

| 命令 | 正则 | 优先级偏移 |
|---|---|---|
| `#危战 [版本/首领/角色]` | `raidTiers` `/^#?危战(?:\s+([\s\S]+))?$/` | -5 |
| `#练度查询 胡桃 [UID]` | `grade` `/^#?练度查询(?:\s+([\s\S]+))?$/` | -5 |
| `#队伍伤害 胡桃 行秋 夜兰 钟离` | `teamDamage` `/^#?队伍伤害(?:\s+([\s\S]+))?$/` | -5 |
| `#配装 胡桃 [名次]` | `akashaBuild` `/^#?配装(?:\s+([\s\S]+))?$/` | -5 |
| `#胡桃dps [金数]` | `charDps` `/^#?([^#\s]\S{0,10}?)\s*[dD][pP][sS](?:\s+([\s\S]+))?$/` | -5 |

- **判定顺序**（`matchEntryCommand`）：`raidTiers → grade → teamDamage → akashaBuild → charDps`（`#危战` 更具体，排最前）。
- 与 `DPS_RULES` **分开维护**：那一份是合并前的冻结面，新入口不混进去。
- `charDps` 要求 `dps` 前有角色名，因此 `#DPS榜` / `#DPS状态` 不会被它吞掉。

## 路由优先级与放行边界

| 处理者 | priority | 说明 |
|---|---|---|
| 本插件 · 攻略 / 帮助 | **-100000**（`PREEMPT_PRIORITY`，写死不可配置） | 早于 Atlas 快捷入口（-99999）与 `plugins/genshin`「米游社攻略」（50） |
| 本插件 · `#DPS…` 与 v3 入口 | `config.priority`（默认 **8000**）+ 各命令偏移 | 高于 Atlas 默认 10000 |
| Atlas-Plugin | -99999（快捷入口）/ 10000（默认） | 图鉴类命令**逐字不变**：本插件 `accept()` 只认领自己的消息，其余全部放行 |

`#设置默认攻略N` **不接管**，由 `plugins/genshin` 继续处理。

## 账号与隐私口径

- **凡涉及"我的账号"的命令都不带 UID**：`#练度查询` 只接角色名，账号走 miao 的米游社绑定（用户 `#扫码登录` 一次）。
- 例外：`#DPS练度查询 [角色] [UID]`（阿卡莎名次面板）与 `#队伍伤害 … [UID]` 仍可显式写 UID。
- 米游社 ck 由 miao 保存；本插件不保存凭据，状态页只回显"是否配置代理"。

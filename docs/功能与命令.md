> 本册是**命令全集与触发口径**的唯一维护处。命令文案、正则、优先级的**代码来源**是

## 帮助入口（两小一大）

| 入口 | 页面内容 | 规则 |
|---|---|---|
| `#meta` / `#Meta帮助` | 总帮助 | `META_HELP_RULE` `/^#?(?:meta\|Meta\|META)(?:帮助\|说明)?$/` |
| `#攻略帮助`（= `#攻略` / `#攻略说明`） | 攻略 + 练度 | `HELP_RULE` `/^#?攻略(?:说明\|帮助)?$/` |
| `#DPS帮助` | 伤害 + 榜单 + 状态 | `RULES.help` |

三者由同一个 handler（`src/apps/help.ts` 的 `MetaHelp.handleHelp`）出图，**渲染失败回落同源文本**。

## 攻略入口（后缀式）

| 命令 | 规则 |
|---|---|
| `#胡桃攻略` / `#胡桃攻略2` / `#胡桃指南` | `CODEX_SUFFIX_RULE` `/^#?(更新)?(?!.*设置默认攻略)([^#\s]\S*?)攻略([1-7])?$/` |
| `#攻略列表` / `#攻略状态` | `CODEX_META_RULE` `/^#攻略(列表\|状态)$/` |

- 三个全局词 `#攻略` / `#攻略帮助` / `#攻略说明` 由帮助 app 认领（`accept()` 只认领它们与 `#meta`）。

## 练度榜口径（`#练度榜`，2026-10-16 合并）

- **一条命令两个视图**（同一个取数结果，按有没有写名次分流）：
  - `#练度榜 胡桃` → **前 20 名列表**（模板 `resources/dps/build.html`，头卡 = 第 1 名，列表中该行高亮）；
  - `#练度榜 胡桃 3` → **第 3 名的配装详情**（模板 `resources/dps/akasha-build.html`，原 `#配装 胡桃 3`）。
- **数据源 = 阿卡莎角色榜**（`/api/leaderboards?calculationId=<角色 id × 100>`，浏览器会话取数）：
  这是**榜单数据，与查询者账号无关**；页面与文本回退里**都不出现任何 UID**（既不是查询者的，也不展示上榜者的）。
- **第二个参数是名次**（1~50；`第3名` / `3位` / `#3` 也认）：不是 UID。**纯数字参数**（如 9 位 UID）→ **静默不回复**；
  完全不写参数 → 回用法提示。名次超过榜单条数 → 回一句「这个榜单只有 N 条（你要的是第 M 名）」。
- **页面元素底 / 元素强调色**：`<body class="elem-{元素}">`，元素取自本地角色表里**被查询角色**的 `element`
  （`build.ts` 的 `elementClassOf()` → `anemo` / `pyro` …；取不到就空类，退回中性渐变），
  由 `resources/common/base.css` 的 `body.elem-*` 铺 `--page-art`（元素底）与 `--page-acc`。
- **数值口径随榜，不写死「伤害」（2026-10-17 修正）**：阿卡莎每个角色可开 **1~6 个榜**（全站 133 个榜 / 60 个角色），
  **榜的口径不都是伤害**——实测：钟离默认榜 `Shieldbot, Max HP`（数值 = **生命值上限**）、
  克洛琳德 `… Combo, DPS`（**每秒伤害**）、申鹤 `Simulated Buff`、琴/心海/迪奥娜/枫原万叶 `… balance formula`（伤害与属性合成公式）、
  优菈 `C6 Lightfall Sword Explosion Crit DMG`（单次伤害）、妮露 `Damage Contribution`（伤害贡献）。
  所以：榜名进**副标题**、数值标签由榜名推（`modules/akashaBoard.ts` 的 `metricLabelOf()` → `生命值上限` / `DPS` / `平均伤害` / `平衡公式` / `模拟增益` / `伤害贡献` / `单次伤害` / `扩散伤害` / `公式结果`，≤5 字不折行），
  页脚写明「该榜公式结果，非 DPS」；取不到榜名时退回中性的「结果」。
- **页面章节顺序**（2026-10-17 用户定）：配装详情页 = **01 面板 → 02 配装 → 03 该榜数值与评分**（原 01 与 03 对调）。
- **默认榜**：`calculationId = 角色id × 100 + (分类 index − 1)`，`#练度榜` 取 **index 1**（实测三榜逐一核对）。
  榜清单与口径说明见 `Character-Codex-Data/阿卡莎榜清单.md`（抓取于 2026-10-17，站点 `GET /api/v2/leaderboards/categories` 不带参 = 全站清单）。
- **中文化（2026-10-17 用户定："不要机翻，参照游戏实际"）**：角色名 / 武器 / 套装 / **圣遗物主词条**一律走站点
  `/api/textmap/zh-CN` 的**官方译名**（`modules/akashaBoard.ts` 的 `textmapWords()` 负责把这几类英文词一起送出去；
  漏送主词条会导致详情页显示 `HP%` / `Crit DMG`）；**用户名（昵称）原样显示，不翻译**；
  **榜名与口径说明站点没有中文**（只有 `Max HP → 生命值上限` 之类），故榜名原样显示英文；
  站点被 Cloudflare 拦住时逐项回落英文原文（既有降级口径）。
- **套装表述**与练度页同一份规则（`setSummary()`）：只写 4 件套 / 2+2 / 2 件套，**不列单件散件**，凑不出加成写「散件」。
- 原 `#配装` 命令**直接删除、不做别名**（用户 2026-10-16 定）；通道开关统一由 `modules.build` + `akashaEnabled` 管。

## 练度评分口径（`#练度查询`，2026-10-15 用户定）

- **三维加权**（`gradeWeights`，默认 `comprehensive:65,weapon:20,talent:15`）：
  `综合`（**圣遗物有效词条**为主 = miao 评分档位 ×0.8 + 套装符合度 ×0.2）/ `武器`（是否在推荐档）/ `天赋`（目标等级）。
- **面板与圣遗物已合并**：面板数值本来就是武器与圣遗物词条的产物，分两维等于把同一件事算两次。
- **面板目标不计分、不设严格限制**：攻略里的面板区间只在对比表的「参考」组展示（`verdict: info`），
  不进总分、也不进"未达标项"。
- **毕业档**（大毕业 / 毕业 / 小毕业）按**综合（词条）分**判定；等级不足时最高「小毕业」。

## 账号与隐私口径

- **凡涉及"我的账号"的命令都不带 UID**：`#练度查询` 只接一个角色名，账号走 miao 的米游社绑定（用户 `#扫码登录` 一次）。
  `#练度查询 胡桃 100000000` 这类 UID 形态属**遗留写法**，2026-10-15 起不再支持：app 会回一句改用提示并指向 `#练度榜`。
- **`#练度榜` 也不再收 UID**（2026-10-16 起）：它的第二个参数是**名次**，纯数字参数静默不回复。
- 例外：`#队伍伤害 … [UID]` 仍可显式写 UID。
- 米游社 ck 由 miao 保存；本插件不保存凭据，状态页只回显"是否配置代理"与"已关闭的模块"。
